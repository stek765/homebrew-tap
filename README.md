# homebrew-tap

Homebrew tap of [stek765](https://github.com/stek765).

```bash
brew install --cask stek765/tap/onebox
```

| Cask | What it is |
|---|---|
| `onebox` | [Onebox](https://github.com/stek765/OneBox): macOS menu bar app with WhatsApp, Telegram, Slack, Discord, Proton Mail and LinkedIn in one panel (Apple Silicon, not notarized: see the Onebox README for the first launch). |

## Updating a cask

Edit `version` and `sha256` in `Casks/onebox.rb` (`shasum -a 256 <file>.dmg`).
